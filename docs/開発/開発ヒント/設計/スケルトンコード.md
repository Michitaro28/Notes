# スケルトンコードとは

スケルトンコードは「処理の中身」は書かずに、全体のクラス、メソッドだけを先に作り、責任や流れだけを示したコードを指します。
戻り値や引数、コメントで何を受け取り何を返すかを表現し、役割や繋がりをみえるようにすることを重視する。


## FB
- 全体の流れについてはクラス図を作成し、実装を行った。
